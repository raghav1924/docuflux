# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security issue, path traversal vulnerability, or parsing bug in DocuFlux, please send an email to **[raghavjatin245@gmail.com](mailto:raghavjatin245@gmail.com)**.

Please include:
1. Vulnerability description and steps to reproduce.
2. Sample codebase or file structure triggering the issue.
3. Potential severity and impact.
